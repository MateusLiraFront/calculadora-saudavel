### Calculadora Saudável 🥗
Projeto desenvolvido para praticar e consolidar conceitos da linguagem TypeScript integrados ao ecossistema Node.js.

### 🎯 Sobre o Projeto
O Calculadora Saudável é uma aplicação voltada para o acompanhamento e atualização diária de metas saudáveis. O sistema permite monitorar indicadores essenciais de saúde, nutrição e desempenho físico
